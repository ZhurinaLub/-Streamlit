## 📋 О проекте

Данный проект представляет собой веб-приложение для анализа и прогнозирования здоровья собак на основе синтетических данных. Приложение позволяет:

- 📊 Загружать и визуализировать данные о собаках
- 🔍 Фильтровать данные по различным параметрам
- 🤖 Предсказывать здоровье собаки с помощью модели машинного обучения

Проект выполнен в рамках учебного задания по курсу Streamlit и демонстрирует навыки работы с:
- Streamlit для создания веб-интерфейса
- Pandas для обработки данных
- Scikit-learn для машинного обучения
- GitHub для хранения кода

## 🎯 Функциональность

### Задание 1 (Промежуточное)
- ✅ Загрузка и отображение данных
- ✅ 6+ интерактивных контролов:
  - Мультивыбор пород
  - Слайдер для веса
  - Выбор уровня активности
  - Чекбокс "Только здоровые"
  - Радио-кнопка для типа графика
  - Кнопка предсказания
- ✅ Визуализация данных (гистограммы)

### Задание 2 (Основное)
- ✅ Двухфайловая структура проекта
- ✅ Модель машинного обучения (Random Forest Classifier)
- ✅ Прогнозирование здоровья собаки на основе введенных параметров
- ✅ Отображение вероятности предсказания
